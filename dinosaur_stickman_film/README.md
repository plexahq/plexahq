# The Last Day of the Dinosaurs

A 4 min 44 s animated short film: a black stickman, a portal in the bedroom wall, the age
of dinosaurs, a T-Rex chase and the asteroid that ended it all. There is no dialogue and no
narration. Everything you see and hear is generated by the code in this folder: no stock
footage, no samples, no AI video service.

**Final film:** [`final/final_dinosaur_adventure.mp4`](final/final_dinosaur_adventure.mp4)
(H.264 High, 1920×1080, 24 fps, AAC 48 kHz stereo). The same file is also at
`../final/final_dinosaur_adventure.mp4` in the repository root.

## What is in here

```
dinosaur_stickman_film/
├── engine/              reusable animation engine (Python + Skia)
│   ├── core.py          maths, easing, noise, colour, paths, camera with parallax, layers
│   ├── stickman.py      the stickman rig: FK/IK skeleton, eyes, gait cycles, pose tracks
│   ├── dino.py          T-Rex / small theropod rig, front-view T-Rex, sauropod, pterosaur, birds
│   ├── nature.py        skies, clouds, fractal mountains, volcano, trees, ferns, grass, water, mist, light rays
│   ├── fx.py            particles, dust, splashes, portal, light tunnel, fire, mushroom cloud, shockwave, ash
│   └── post.py          vignette, film grain, fades
├── scenes/              the film: one module per scene (s01 … s17) + shared sets
│   ├── bedroom.py       Act 1 set
│   ├── prehistoric.py   landscape kit and palettes, endless forest for tracking shots
│   └── vista.py         the mountain-top panorama (Acts 4–5)
├── audio/
│   ├── synth.py         synthesiser: strings, brass, piano, celesta, choir, drums, roars, splashes…
│   ├── soundtrack.py    the score and sound design, synced to scene cues; mixing and mastering
│   └── soundtrack.m4a   the finished soundtrack (AAC)
├── scripts/
│   ├── render.py        stills, contact sheets, preview or full render (parallel, piped to FFmpeg)
│   ├── finalize.py      mux picture and sound into the final MP4 (keeps it under 100 MB)
│   ├── qc.py            automated quality control + contact sheet
│   └── model_sheets.py  character model sheets
├── assets/              fonts (Cinzel, SIL OFL), model sheets, storyboard contact sheet
├── renders/             intermediate renders (ignored by git, except the QC report)
├── final/               final_dinosaur_adventure.mp4
└── SCENES.md            scene breakdown with timecodes and shot list
```

## How it works

- **Picture.** Each frame is painted on the CPU with [Skia](https://skia.org) (via `skia-python`)
  at 1920×1080. Scenes are pure functions of time, `render(canvas, t)`, so any frame can be drawn on its
  own and the film renders in parallel. Characters are skeletal rigs. The stickman has fixed
  proportions, two-bone IK legs whose phase is integrated from distance travelled (feet never
  slide), and white eyes for expression. The dinosaurs are built from a spine with a thickness
  profile, giving one organic outline that bends, plus IK digitigrade legs, a hinged jaw,
  teeth, a blinking eye and a swaying tail. Environments use parallax layers, cached sprites,
  atmospheric haze, depth-of-field blur, god rays, colour grading, vignette and grain.
- **Sound.** `audio/synth.py` synthesises every instrument and effect with numpy/scipy
  (subtractive strings and brass, additive piano and celesta, formant choir, taiko, a
  formant-filtered growl for the T-Rex roar, layered explosion…). `audio/soundtrack.py` reads the
  cue times that each scene publishes (`CUES`), so every footstep, splash, roar and hit lands on
  the picture. The mix uses convolution reverb, a slow music leveller and a peak limiter, and
  is measured with EBU R128.

## Reproduce the film

You need Python 3.10+, FFmpeg with libx264, and on Linux the EGL/GL libraries that
`skia-python` links against.

```bash
sudo apt-get install -y ffmpeg libegl1 libgl1
```

```bash
pip install -r requirements.txt
```

Then, from this folder:

```bash
python3 audio/soundtrack.py
```

```bash
python3 scripts/render.py film --workers 4
```

```bash
python3 scripts/finalize.py
```

```bash
python3 scripts/qc.py
```

The first command writes `audio/soundtrack.wav` (about 30 s). The full picture render takes about
10 minutes on 4 CPU cores. Useful while editing:

```bash
python3 scripts/render.py info
```

```bash
python3 scripts/render.py stills 106.5 254.8 --scale 0.5
```

```bash
python3 scripts/render.py sheet --start 95 --end 115 --every 1 --scale 0.25
```

```bash
python3 scripts/render.py video --start 95 --end 115 --scale 0.5 --out renders/trex.mp4
```
