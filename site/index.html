10 · Questions

Asked and answered.

What is MCP?

The Model Context Protocol is an open standard that lets AI assistants call external tools. Claude, ChatGPT, Cursor and VS Code all support it. Plexa is an MCP server: you add its URL and your assistant can use its tools.

Does Plexa hold my keys or funds?

No. Plexa is read-only. It never asks for a private key, never holds assets and never sends a transaction. Future signing will always happen in your own wallet.

Which chains are supported?

Ethereum, Base, Arbitrum and HyperEVM today, plus their Sepolia testnets, and the entire LayerZero network for message tracking. Zero's ATLAS and Interop zones switch on at mainnet.

What is Zero?

Zero is LayerZero's new blockchain, built from specialised zones for trading, interoperability and payments. Mainnet is scheduled for November 30, 2026.

Is it free?

Yes, during launch. Add the URL and start asking.

How does simulation work?

Plexa runs your transaction against the chain's live state without broadcasting it, decodes the call using verified contract code, estimates the fee and flags known drainer patterns.

Is Plexa affiliated with LayerZero?

No. Plexa is an independent project that builds on LayerZero's public infrastructure and APIs.

Where does the data come from?

Straight from the source: RPC nodes for chain state, LayerZero Scan and LayerZero's deployment registry for cross-chain messages, and Sourcify for verified contract code.
