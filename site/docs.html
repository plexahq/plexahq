01 · Getting started

Overview

Plexa is the MCP gateway for LayerZero's Zero and every EVM chain. You add one URL to your AI client, and your assistant can read wallets and contracts, simulate transactions before you sign, and follow cross-chain messages, all from a normal chat.

5 min read · Updated November 2026 · v0.1

QuickstartConnect Claude, Claude Code, ChatGPT, Cursor or VS Code in a minute. ToolsAll sixteen tools with inputs, outputs and an example for each. Safety modelRead-only by design. What Plexa checks before you sign. HTTP endpointsThe MCP endpoint, health check and live data feed.

What sets it apart

  • Built for Zero. LayerZero's new chain is wired in before launch; its zones switch on with one line of configuration.
  • Cross-chain native. Any LayerZero message can be tracked by its source transaction, with every DVN named.
  • Trust, checked. Any LayerZero app's verifier setup and who controls it, read straight from the chain.
  • ZRO and markets. ZRO on every chain, and tokenized stocks and ETFs by ticker or by wallet.
  • Simulation first. Transactions are dry-run on live state and explained before anyone signs anything.
  • No keys, no accounts. Plexa never asks for a private key and needs no sign-up.

Getting started

Quickstart

Everything starts with one URL. No API key, no wallet connection.

https://plexahq.vercel.app/mcp

Claude (web, desktop, mobile)

  1. Open Settings → Connectors.
  2. Choose Add custom connector, paste the URL and save.
  3. Enable Plexa in a chat and ask away.

Claude Code

claude mcp add --transport http plexa https://plexahq.vercel.app/mcp

ChatGPT

Add a custom MCP connector in ChatGPT's settings and paste the URL. No authentication is required.

Cursor

Add to ~/.cursor/mcp.json:

{ "mcpServers": { "plexa": { "url": "https://plexahq.vercel.app/mcp" } } }

VS Code

Add to .vscode/mcp.json, then start the server from the MCP view and use it in agent mode:

{ "servers": { "plexa": { "type": "http", "url": "https://plexahq.vercel.app/mcp" } } }

Reference

LayerZero tracking

A LayerZero message is sent on a source chain, verified by the application's DVNs (decentralised verifier networks), then executed on the destination chain. lz_track_message takes the source transaction hash and reports where the message is, names each DVN and explains the status:

StatusWhat it means
INFLIGHTSent and on its way; DVNs are verifying. Delivery normally follows within minutes.
CONFIRMINGWaiting for enough block confirmations on the source chain.
DELIVEREDVerified and executed on the destination chain. Nothing else to do.
PAYLOAD_STOREDVerified, but execution reverted; the payload is stored and can be retried.
BLOCKEDAn earlier message on the same ordered pathway hasn't been delivered yet.
FAILEDDelivery failed on the destination chain.

Reference

Trust check

Every LayerZero app (an OApp, or an OFT token) chooses who verifies its messages. lz_app_security reads that choice from the chain, for each connected chain and in both directions, and explains it:

It reportsWhy it matters
DVNs needed, by nameHow many independent verifiers must sign before a message counts. One is a single point of failure; two or more is the norm for serious apps.
Block confirmationsHow long the source chain must settle before verifiers sign.
Settings sourceWhether the app set its own values or inherits LayerZero's defaults, which can change without the app's involvement.
Owner and delegateWho can change peers and verifier settings: a single key, a multisig (with its threshold) or a contract such as a timelock.
low medium highHigh when any pathway can be approved by one DVN; medium when one key controls the settings; low otherwise. Closed pathways (dead DVN or blocked library) are noted, not scored.

It is an automated read of the configuration at that moment, not an audit of the app's code.

Reference

ZRO & markets

zro_overview reads ZRO's supply on Ethereum, Arbitrum, Base, BNB Chain, OP Mainnet, Polygon and Avalanche. ZRO is a LayerZero OFT at the same address on each, so the supplies add up to the total. Given a wallet, it lists that wallet's ZRO everywhere; LayerZero has said ZRO will pay for gas on Zero.

stocks_lookup and stocks_portfolio cover tokenized stocks and ETFs issued by Ondo Global Markets on Ethereum and BNB Chain, using Ondo's public token list. They report token supply and holdings. They do not report prices, and Plexa does not offer or trade these tokens.

03 · Trust

Safety model

Plexa is read-only. It never asks for a private key, holds no funds and never broadcasts a transaction. When signing arrives, transactions will be prepared by your assistant, simulated by Plexa and signed by you, in your own wallet.

What simulation flags

  • Transactions that would revert, with the decoded reason
  • Unlimited ERC-20 approvals, and approvals to addresses with no contract code
  • Tokens sent to the token's own contract address
  • Calls to contracts with no verified source on Sourcify
  • EIP-7702 delegations to unverified code
  • Native value larger than the sender's balance

Simulation reflects the chain state at the moment it runs; state can change before a real transaction is mined.
